# Project Context

Unofficial snap package for Mylar3 comic book downloader.

## Language & Style

- Technical and straightforward
- Concise descriptions
- No marketing language or selling points
- Direct, practical information only
- Short sentences and bullet points preferred

## Key Points

- This is an unofficial snap (not affiliated with Mylar3 upstream)
- Runs as daemon with root privileges
- File access limited by snap confinement
- Automated release tracking via GitHub Actions

## When Making Changes

- Keep documentation minimal and factual
- Use inline comments in code blocks rather than verbose explanations
- Focus on "what" and "how", not "why you should"
- List issues and limitations upfront
- Avoid superlatives and excessive praise

## Repository Structure

- `snap/snapcraft.yaml` - Snap build configuration
- `README.md` - User-facing documentation
- `WORKFLOW.md` - Maintainer workflow documentation
- `.github/workflows/` - Automated release tracking

## Snap Features

CLI commands:
- status, logs, config-dir, health-check, backup, restore

Configuration via snap set:
- port, verbose, auto-backup, disable-weekly-check

## Testing

Build locally: `snapcraft`
Install: `sudo snap install --dangerous *.snap`
